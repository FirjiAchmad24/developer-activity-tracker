# Developer Activity Tracker

A lightweight GitHub automation project for tracking developer activity and maintaining a structured daily development log.

## 🎯 Purpose

This repository is designed to experiment with GitHub Actions, scheduled automation, Git workflows, and developer activity tracking.

The system will automatically maintain structured development activity records while clearly distinguishing automated activity from manual development work.

## 🚀 Planned Features

- Daily developer activity tracking
- GitHub Actions automation
- Automatic activity log generation
- Contribution status checking
- Scheduled workflow using WITA timezone
- Developer statistics
- Monthly activity summaries
- Automatic fallback activity log
- Manual workflow execution for testing

- Git
- GitHub
- GitHub Actions
- Python
- JSON
- Markdown
